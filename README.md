# Jeu Entrepreneurs

Un petit jeu web pour associer des entrepreneurs célèbres à la logo de l'entreprise qu'ils ont créée ou développée. Quand une paire est correcte, une description du style entrepreneurial apparaît.

## Jouer en local

Ouvre `index.html` dans un navigateur.

## Déploiement GitHub Pages

Dans les paramètres du dépôt GitHub, active GitHub Pages avec la branche `main` et le dossier racine (`/`). Le jeu est entièrement statique.
